# Portfolio Positioning Notes

## Suggested project description

Built a local financial-operations analytics platform that validates synthetic operational records, detects and prioritizes data-quality exceptions, calculates operational KPIs, tracks remediation actions and risks, and generates executive-ready dashboards and reports.

## Skills to highlight

Python, SQL, Pandas, FastAPI, SQLite, Streamlit, Plotly, Excel automation, data quality, KPI analytics, exception management, process improvement, REST APIs, testing, Git, Docker.

## Interview themes

Be prepared to explain:
- Why validation matters.
- How validation rules are structured.
- How exception severity differs from priority.
- How SLA compliance is calculated.
- How duplicate detection works.
- How synthetic data was generated.
- Why SQLite was chosen.
- Why Streamlit was used instead of Power BI.
- How tests protect KPI correctness.
- How recommendations are derived.
- What would change for a production implementation.

Never claim:
- access to State Street systems
- real financial data
- production deployment
- industry-standard scoring unless independently supported
