# Start Here

Open `CODEX_MASTER_PROMPT.md` and give it to Codex with this entire repository as the working directory.

The intended workflow is:

1. Read all markdown files.
2. Implement the platform from `SPECIFICATION.md`.
3. Follow `IMPLEMENTATION_PLAN.md`.
4. Validate against `TEST_PLAN.md`.
5. Do not mark complete until `DEFINITION_OF_DONE.md` is satisfied.
6. Keep `docs/REQUIREMENTS_TRACEABILITY.md` updated.

This package intentionally contains specifications and execution instructions rather than prebuilt application code. Codex is expected to generate the application from these documents.
